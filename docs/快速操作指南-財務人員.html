資金週報系統　快速操作指南（財務人員）

從首頁「現在該做的事」開始，照任務卡操作。按鈕與欄位名稱皆採用系統畫面原文。

從首頁「現在該做的事」開始

登入後首頁最上方會列出現在該處理的事，每一項右邊一個按鈕，直接跳到要操作的頁面，不用自己想要去哪裡。

這一項意思按下去之後做什麼
週期範本（含借款還款）固定收支或借款還款到期了確認實際日期與金額，按「確認入帳」，系統一次記好收支、還款記錄並順延下次日期
借款「○○」該還款了沒有連結範本的借款下次還款日到了在還款記錄登記本金與利息
定存已到期定存到期還沒確認銀行入帳後按「解約／到期」，利息改成實際金額
帳戶沒有期初結算／太久沒結算系統無法計算餘額，或已超過 35 天沒對帳到餘額結算輸入銀行實際餘額

日常流程

第一次建置（只做一次）

  1. 公司管理：建立公司。
  2. 銀行帳戶：建立帳戶並設定安全水位。
  3. 餘額結算：每個帳戶建「期初餘額」。
  4. （有借款）借款管理：新增借款，匯入銀行給的還款計畫表。
  5. （固定支出）週期範本：建立房租、保費、借款還款。

平常

  1. 每天／每筆：收支記錄「➕ 新增」；很多筆就「📋 貼上匯入」。
  2. 固定支出與借款還款：首頁待辦或週期範本按「確認本期入帳」。
  3. 月底：餘額結算輸入銀行實際餘額，看差異是否為 0。
  4. 存定存／解約：銀行帳戶的「轉定存」「解約／到期」。

記帳最重要的三件事：①公司、帳戶一律從下拉選單選，不要手打；②每個帳戶先建期初結算；③日期早於結算日的收支不會影響目前餘額。

⚠️ 資金預估週報　資金預估週報

這一頁回答一個問題：「各銀行帳戶接下來的餘額夠不夠？」系統從最近一次結算的餘額往後推，加上已登記與預計的收支，在每個「檢查日」算出預計餘額，低於安全水位就標示資金缺口。

看懂畫面

帳戶為欄、日期為列
每一欄是一個銀行帳戶，每一列是一天的收支。
黃底列（結餘檢查點）
預設每月 15 號與 30 號，看這天各帳戶的預計餘額。
斜體「（預計）」列
依借款還款、週期範本、定存到期「推算」的預估，不是真實交易，不影響真實餘額；實際登記後會被真實交易取代。
上方三個數字
可用資金（活存＋定存）、目前貸款餘額、兩者相減；藍底＝可用資金夠還貸款，紅底＝不夠並標示短少多少。
資金缺口
安全水位 − 預計餘額。預計餘額沒低於安全水位，缺口就是 0。

我想要…

我只想看某幾個帳戶

  1. 按工具列的「🏦 顯示帳戶」。
  2. 勾選要看的帳戶（可「全選」「取消全選」）。

我想確認某一段時間的收支有沒有對

  1. 勾選工具列的「顯示區間驗算」。
  2. 每個黃底檢查點下方會多一列：上期餘額 ＋ 收入 − 支出 ＝ 本期餘額。
  3. 顯示 ✓ 代表對得上；橘色 ⚠ 會顯示差額。
  4. 點營業收支的金額，可直接開啟該區間、該帳戶的收支記錄。

我想知道「目前貸款餘額」包含哪些借款

  1. 點該數字旁邊的「明細」。
  2. 要修正數字，請到「💳 借款管理」改那一筆借款。

我想用手機看

  1. 流水帳是寬表格，請左右滑動。
  2. 也可以切到「📇 帳戶卡片」，一個帳戶一張卡片，比較好讀。

我想知道某個月的收支

  1. 點月份標題展開或收合；預設只展開當月起的六個月。
  2. 也可以按「全部展開」「全部收合」。

常見疑問

為什麼餘額跟銀行不一樣？
餘額是從最近一次「結算」往後算的。請財務人員到「✅ 餘額結算」輸入銀行實際餘額，系統會顯示差異，再檢查是否漏登或重複。
為什麼某筆預計沒出現？
預計只顯示往後一年；若是借款，到「💳 借款管理」看該筆的「資金預測」欄，會寫明原因。

💰 收支記錄　收支記錄

所有真實的收入與支出都記在這裡，餘額就是由這些記錄加上最近一次結算算出來的。上方三個數字是目前篩選結果的總收入、總支出、淨收支（帳戶間轉帳不計入）。

看懂畫面

公司 → 帳戶 要用下拉選單選
系統用「公司＋帳戶名稱＋帳號」對應銀行帳戶，手打錯一個字，這筆就不會算進任何帳戶。
轉帳徽章
帳戶間轉帳會標示徽章，不計入收入／支出，只能整組刪除。

我想要…

我想查某個帳戶或某段期間的收支

  1. 在篩選區選開始／結束日期、公司、帳戶，或輸入關鍵字。
  2. 按「🔍 查詢」；要還原按「清除篩選」。
  3. 點欄位標題可排序。

新增一筆收入或支出財務人員／管理員

  1. 按「➕ 新增收支記錄」。
  2. 填交易日期、類型（收入／支出）、金額（有 * 的必填）。
  3. 選公司，再選帳戶（帳號會自動帶入）。
  4. 按「儲存」。

日期若早於該帳戶最近結算日，會出現橘字提醒：這筆會留在記錄裡，但不會算進目前餘額。

一次匯入很多筆（從 Excel 複製貼上）財務人員／管理員

  1. 按「📋 貼上匯入」。
  2. 在 Excel 選取要匯入的儲存格（可含表頭），Ctrl+C。
  3. 點視窗的輸入框，Ctrl+V，下方立刻出現預覽。
  4. 看「檢查結果」欄：✓ 可匯入、✗ 有錯誤、⚠ 要留意；每一格都能直接修改。
  5. 全部沒有錯誤後按「確認匯入」。

疑似重複的列預設不勾選；單次最多 1000 筆，整批全有或全無。

在兩個帳戶之間轉錢財務人員／管理員

  1. 按「🔁 轉帳」。
  2. 填轉帳日期、金額、轉出帳戶、轉入帳戶。
  3. 銀行另外收手續費的話，填在「手續費」欄（選填）。
  4. 按「確認轉帳」。

手續費會另記一筆類別「手續費」的支出（扣在轉出帳戶），不併入轉帳金額，統計報表才看得到；事後才知道手續費，到「新增收支記錄」補登一筆類別「手續費」的支出即可。轉到定存請改用「🏦 銀行帳戶」的「轉定存」，才會記錄利率與到期日。轉帳日期早於某個帳戶最近一次結算時，那一腿不會影響該帳戶的目前餘額（視窗會用橘字提醒）。轉帳不能編輯，做錯請刪除後重建。

一次修改多筆記錄的日期財務人員／管理員

  1. 在列表勾選要改的記錄。
  2. 按「📅 批次修改日期」。
  3. 選「全部改成指定日期」或「全部順延 N 天」（往前填負數）。
  4. 下方會即時預覽每一筆「原日期 → 新日期」與提醒。
  5. 確認摘要沒問題，按「確認修改」。

轉帳只要勾到任何一腿，另一腿會自動一起修改。新日期早於該帳戶最近結算日時，那一筆不會影響目前餘額；若記錄可能對應借款還款，借款那邊的還款日期不會跟著變，請到借款管理確認。單次最多 500 筆。

刪除記錄財務人員／管理員

  1. 單筆：按該列的「刪除」。
  2. 多筆：勾選多列，按「🗑️ 批次刪除」。
  3. 刪除後相關帳戶餘額會自動重算。

常見疑問

轉帳後轉出的帳戶沒減少、轉入的卻增加？
轉帳日期早於轉出帳戶最近一次結算時，那一腿不會影響它的目前餘額（結算金額已視為包含）。請確認該帳戶的結算是否已包含這筆。
登記了但餘額沒變？
先看日期是否早於該帳戶最近結算日，或公司／帳戶／帳號沒有選到正確的銀行帳戶。
匯入時顯示「找不到帳戶」？
貼上匯入的帳戶要和銀行帳戶管理裡的名稱一致；同名帳戶請在預覽表的下拉選單指定。

✅ 餘額結算　餘額結算

「結算」是把銀行實際餘額登錄進系統，當作之後計算餘額的起點，同時比對系統算的和銀行實際差多少。每個帳戶第一次使用前，一定要先做一筆期初結算。

看懂畫面

差異
實際餘額 − 計算餘額，儲存後在「結算歷史記錄」查看。差異不是 0，代表漏登、重複登，或帳戶選錯。
結算日當天的收支
實際餘額請填「結算日當天開始前」的銀行餘額（前一天收盤餘額），當天的收支算在結算之後。

我想要…

第一次使用：建立期初餘額財務人員／管理員

  1. 選結算日期、公司、帳戶，按「📊 計算結算」。
  2. 在下方勾選「我要輸入銀行實際餘額」。
  3. 輸入銀行對帳單上的實際餘額（結算日當天開始前的餘額）。
  4. 按「💾 儲存結算記錄」。

找不到帳戶時，按「➕ 快速新增帳戶」，填名稱、帳號、銀行、類型，按「儲存並選用」。

月底用銀行餘額對帳財務人員／管理員

  1. 選結算日期、公司、帳戶，按「📊 計算結算」，看系統算出的計算餘額。
  2. 勾選「我要輸入銀行實際餘額」，輸入銀行對帳單的餘額。
  3. 輸入餘額時，下方會即時顯示「差異」（實際餘額 − 計算餘額）；是 0 就對上了。
  4. 差異是「系統比銀行多」的小金額（通常是銀行扣了手續費還沒登記）時，可以勾選「把這筆差異補登為手續費支出」，儲存後差異就變 0。
  5. 按「💾 儲存結算記錄」。

差異超過 1 萬元不提供補登手續費，多半是漏登其他收支或帳戶選錯，請回「收支記錄」檢查。補登的手續費日期是結算日前一天。沒有勾選「我要輸入銀行實際餘額」就儲存，只會把系統算出的餘額存成結算，不會和銀行比對。

查看歷史結算

  1. 下方「結算歷史記錄」列出每次結算的期初、收入、支出、計算餘額、實際餘額與差異。

常見疑問

可以不結算嗎？
沒有結算，系統就沒有起點，無法計算餘額。至少要有一筆期初結算。

🏦 銀行帳戶　銀行帳戶管理

每家公司的銀行帳戶都在這裡維護。「安全水位」是該帳戶最低要保留的金額，預計餘額低於它就會出現資金缺口。活存可以轉定存，定存到期或解約再轉回活存。

看懂畫面

即時餘額
最近一次結算 ＋ 之後的收支。
安全水位
這個帳戶最低保留金額，資金缺口依它計算。

我想要…

新增銀行帳戶財務人員／管理員

  1. 按「➕ 新增帳戶」，選所屬公司。
  2. 填帳戶名稱、帳號、銀行、帳戶類型（活存／定存…）、安全水位。
  3. 按「儲存」，再到「餘額結算」建立期初餘額。

活存轉定存財務人員／管理員

  1. 在活存帳戶那一列按「轉定存」。
  2. 填存入日期、金額、年利率、到期日。
  3. 選一個餘額為 0 的定存帳戶，或新增一個。
  4. 按「確認轉定存」。

一個定存帳戶一次只放一筆；要存第二筆請新增另一個定存帳戶。到期日前，預測會自動帶入到期回到活存。

定存到期或解約財務人員／管理員

  1. 等銀行把本金和利息入帳後再操作。
  2. 在定存帳戶那一列按「解約／到期」。
  3. 日期填實際入帳日，利息改成銀行實際入帳的金額。
  4. 按「確認解約／到期」。

系統不會自動入帳，已到期未確認的定存會標示「已到期」。提前解約可以只轉回一部分本金。

查某個帳戶的明細

  1. 按該帳戶的「交易明細」，會跳到收支記錄並自動套用該帳戶的篩選。

常見疑問

銀行定存自動續存怎麼記？
先按「解約／到期」把本金轉回活存，再用「轉定存」存入新的一筆，利率與到期日填新的。

💳 借款管理　借款管理

記錄每一筆借款或融資額度、目前還剩多少本金、下一次要還多少。設好之後，未來還款會自動出現在資金預估週報的「（預計）」列。

看懂畫面

目前本金餘額
原始本金 − 已還的「本金」。只計算還款日 ≤ 今天的記錄，未來日期的還款不會讓今天的餘額變少；利息不會減少本金。
資金預測 欄
告訴你這筆借款有沒有進入資金預估週報、金額怎麼來（依還款計畫表、範本固定金額或借款排程），沒預測會寫原因。

我想要…

我想看某筆借款還剩多少、下次什麼時候還

  1. 在列表找到那筆借款，看「目前本金餘額」與「下次還款」。
  2. 要看每次還款的明細，按該列的「還款記錄」，表格會列出每次的本金、利息與還款後本金餘額。

新增一筆借款財務人員／管理員

  1. 按「➕ 新增借款/額度」。
  2. 填借款名稱、類型、原始本金、公司，並選「撥款/還款帳戶」。
  3. 要讓未來還款出現在預測：填還款頻率、下次還款日、下次還款金額。
  4. 按「儲存」。

如果有建連結的週期範本，預測以範本為準，借款自己的下次還款日／金額就不再用於預測。

登記一次還款財務人員／管理員

  1. 按該筆借款的「還款記錄」。
  2. 按「新增還款」，填還款日期、本金、利息。
  3. 本金和利息要照銀行通知單分開填，利息不會減少本金餘額。
  4. 儲存後，帳戶餘額與收支記錄會同步更新，借款的下次還款日（與連結範本的下次產生日）自動往後推一期。

有週期範本的借款，建議每期直接在「週期範本」按「確認本期入帳」，兩邊結果相同。銀行對帳單有「還款後貸款餘額」時，可填進「銀行還款後本金餘額」，系統會以銀行數字為準並告訴你差多少。

匯入銀行或租賃公司給的還款計畫表財務人員／管理員

  1. 按「還款記錄」，切到「還款計畫表」分頁。
  2. 展開「匯入／更新還款計畫表」。
  3. 從 Excel 複製含表頭的表格（期數、日期、租金、利息、本金攤還、本金餘額）貼上。
  4. 有每期加收營業稅（例如租金的 5%）時，「每期另加費用」選「租金的 %」填 5。
  5. 看預覽的期數與合計無誤，按「確認匯入」，再按「以計畫表餘額校正」。

系統開始記帳之前已還的期數不要匯入：把期數 0 的本金餘額改成開始記帳當時的餘額，只留之後的期數。

目前本金餘額跟銀行對不上財務人員／管理員

  1. 開「還款記錄」，看每一列的「還款後本金餘額」，和銀行對帳單逐期對照。
  2. 從哪一期開始對不上，就是那一期（或前一期）的本金／利息填錯。
  3. 修正後或直接按「以計畫表餘額校正」。

常見原因：把整筆扣款都填成本金、利息沒分開填、有一筆日期在未來。

常見疑問

資金預測欄寫「未預測」？
照欄位上的原因處理，常見：沒設還款帳戶、沒填下次還款金額、下次還款日設在很遠的未來。
計畫表可能需要更新？
代表最近實際還款與計畫表不同（銀行可能調了利率），向銀行拿新試算表重新匯入即可。

🔁 週期範本　週期範本

房租、保費、薪資、借款還款這類固定重複的收支，建成範本。範本不會自動入帳，每期要人工按「確認本期入帳」確認實際金額，系統才會寫入收支記錄。

預測用這個日期往後排；按「確認本期入帳」後會自動往後推一期。
已到期
下次產生日已過但還沒按「確認本期入帳」；預測會把它算在今天。
連結借款
連結後，確認本期入帳會同時記收支與借款還款，並自動推進借款的下次還款日。

新增一個固定收支範本

  1. 按「➕ 新增範本」。
  2. 選類型、頻率（每月／每季／每年）、金額（視為預估值）。
  3. 選公司與帳戶、填下次產生日。
  4. 按「儲存」。

每期固定要做：確認本期入帳

  1. 在該範本列按「確認本期入帳」。
  2. 把「實際入帳日期」「實際金額」改成真實的。
  3. 連結借款時，本金與利息會依還款計畫表自動帶入，可再調整。
  4. 按「確認入帳」。

預設勾選「同時把範本預估金額更新為這次的實際金額」，下次預測會用新金額。

建立借款還款範本

  1. 先到「借款管理」建好借款，並（有的話）匯入還款計畫表。
  2. 新增範本時，「連結借款」選那筆借款，填本金與利息、下次產生日。
  3. 一筆借款只建一個範本，預測才會依計畫表每期金額自動變動。

下次產生日要對得上借款的還款日，才找得到計畫表的那一期（相差 20 天內）。

常見疑問

範本的帳戶出現橘色警示？
代表範本記的帳戶對不上任何啟用中的銀行帳戶，預測與餘額都不會計入。按編輯，重新選公司與帳戶即可。
